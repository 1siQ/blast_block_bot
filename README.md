##Kullanma rehberi
<br>
1- Telefondan USB hata ayıklama modunu açın 
<br>
2- Scrcpy klasöründe yer alan scrcpy.exe dosyasını açın 
<br>
3- Bağlandıktan sonra scrcpy-console.bat dosyasını açın ekranda telefonunuzun ekranı açılacak.
<br>
4- Açılan pencereyi tam ekran yapın.
<br>
5- pot.py dosyasını çalıştırın 3 saniyelik bekleme süresinde teelfon ekranınıza geçin.
